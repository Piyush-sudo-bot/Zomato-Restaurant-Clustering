
# Zomato-Restaurant-Clustering
# 🍴 Zomato Data Analysis & Insights  

## 📖 Overview  
This project focuses on analyzing **Zomato data** to uncover insights into restaurants, cuisines, locations, ratings, and user preferences. The goal is to leverage **data analytics** and **visualization** to better understand customer behavior, restaurant performance, and market trends.  

## 🚀 Features  
- 📊 **Exploratory Data Analysis (EDA)** on Zomato dataset  
- 🍽️ Insights into **cuisine popularity & distribution**  
- ⭐ Analysis of **ratings and reviews** across locations  
- 📍 **Geographical insights** into top food hubs  
- 📈 Visualizations to support decision-making for restaurants and food businesses  

## ⚙️ Tech Stack  
- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly  
- **Visualization Tools:** Power BI / Tableau (optional dashboards)  
- **Environment:** Jupyter Notebook / Google Colab
